# 测试与模拟数据

[英文版](testing.md) · [运行指南](../README.zh-CN.md) · [Sprint 1](sprints/sprint1.zh-CN.md)

NexRun 将确定性的应用检查与真实模型验证分开。模拟回复是用于展示和测试的固定场景，不能替代模型，也不能证明外部服务可用。仓库中的所有测试样例均为项目自编的合成数据。

## 运行检查

按照运行指南启动本地 PostgreSQL、安装锁定依赖并配置 `.env`，然后运行：

```sh
npm run check
npm run build
```

`check` 依次执行 TypeScript、ESLint、精确发布版本的许可证门禁和 Node 测试套件。API 与演示数据测试会创建临时数据库模式，结束后删除；不会重置开发模式。`TEST_DATABASE_URL` 用于单独指定测试数据库，与应用的 `DATABASE_URL` 分开。

2026-11-04 的本地验证通过了全部 65 项 Node 测试、十三项浏览器场景、类型检查、lint、构建，以及覆盖 552 个精确锁定产物的许可证门禁。这些结果不代表远程 CI 已运行或真实服务提供方验证已成功。

运行浏览器测试前，先停止手动启动的 API 和 Web 服务，再运行：

```sh
npm run test:e2e
```

Playwright 占用端口 3001 和 5173，强制使用模拟模式，创建随机 PostgreSQL 模式和临时 Pi 状态，并通过优雅关闭 API 清理这些资源。本地使用已安装的 Google Chrome；CI 使用匹配版本的 Playwright Chromium。浏览器安装步骤见运行指南。这些检查不需要模型凭据。

定位问题时，可以只运行相关文件：

```sh
node --import tsx --test apps/api/test/mock.test.ts
node --import tsx --test apps/api/test/pi-output.test.ts
node --env-file-if-exists=.env --import tsx --test apps/api/test/demo.test.ts
npm run test:e2e -- --grep 'loads earlier history'
```

Pi 宿主生命周期测试仅检查并向自身带标记的子进程发送信号，需要正常的本地进程权限。测试失败应修复或记录，不要仅为通过测试而放宽断言。

## 确定性模拟场景

普通消息会收到根据意图选择的简短建议或问候，不会原样回显完整提问、追加之前的消息或展示聊天记录。英语为回退语言；当前提问中的明确回复语言要求优先，其次按中文字符识别语言。界面语言和历史对话语言不决定回答语言。

以下区分大小写的命令仅用于开发测试。首尾空白会被忽略；中间包含换行或只是长得像命令的输入仍按普通文本处理。可选的单行参数可以选择回复语言；代码和 Markdown 内容保持固定。

| 输入 | 预期行为 |
| --- | --- |
| `Hello` | 简短问候 |
| `请用英文简要回答` | 即使提问为中文，也简要用英语回答 |
| `Reply in Simplified Chinese` | 即使提问为英文，也简要用中文回答 |
| `/slow` | 在约五秒内持续发送累计快照，较早出现部分文本，便于检查停止和重连 |
| `/error` | 先输出部分回复，再产生 `UPSTREAM_ERROR`；已收到的文本保持可见 |
| `/code` | 固定 TypeScript 代码块；复制时保留原始代码及末尾换行 |
| `/markdown` | 固定格式、无害的 XSS 测试字符串、不安全 URL 和正常参考链接；UI 必须阻止活动内容 |
| `/remember release-42` | 确认记住单行值，但不回显该值 |
| `/context` | 只返回本对话最近一次有效的用户记忆值，或本地化的无记忆提示 |

记忆值最多为 80 个 Unicode 字符。只有先前的用户 `/remember` 消息有效，助手消息和无关历史不能替换记忆值。Adapter 不保存跨对话的共享记忆。API 提供最近 100 条历史消息，因此该场景用于验证有界上下文，不是永久键值存储。模拟命令在 Pi 模式下没有特殊含义。

`/markdown` 特意包含不安全文本作为测试数据，用于在不将任意用户输入反射到助手回答中的情况下检查 Markdown 渲染。不要为显示该场景而启用 HTML 执行。

## 导入演示对话

PostgreSQL 运行且 `AGENT_MODE=mock` 时，执行：

```sh
npm run demo:seed
npm run dev
```

导入命令会应用迁移，并将缺失样例加入仅限本机回环地址的开发数据库。它拒绝 Pi 模式、非 PostgreSQL URL、远程主机，以及 `?host=remote.example` 等路由覆盖参数。允许的 URL 查询参数为 `sslmode`、`application_name`、`connect_timeout` 和 `statement_timeout`。它不会调用 Agent、联系模型或排入可执行任务。

全新导入包含七个对话、72 个终态 Run 和 144 条消息：

| 对话 | 内容 |
| --- | --- |
| `Demo · Release checklist` | 三轮英文交流，回答聚焦重点，并准确说明纯文本能力边界 |
| `Demo · 发布准备` | 两轮中文交流 |
| `Demo · Markdown and code` | 两轮交流，包含保留原始文本的代码 |
| `Demo · Recovery examples` | 失败、恢复、停止和中断状态，以及保留的部分文本 |
| `Demo · Long history (60 turns)` | 120 条有序消息，覆盖多页历史和多批次事件 |
| `Demo · Archived conversation` | 保留历史，但不出现在活跃列表中 |
| `Demo · Start a conversation` | 可继续发送新消息的空对话 |

所有导入的 Run 均已终结，所有 outbox 记录均已退役，事件快照可以重建相同的规范消息。活跃列表中显示六个对话。导入的对话可以在模拟模式下正常继续聊天。

固定样例 ID 支持重复导入。再次运行时会跳过已存在的 ID，保留改名、归档、新增消息和无关对话。发现其他所有者占用样例 ID 时，会回滚整批样例事务。没有破坏性的重置命令；归档演示对话与普通对话使用相同 UI。

## 回复边界与覆盖范围

Pi 系统策略要求优先回答关键结论和相关信息，默认简洁，并使用用户要求的语言；用户明确要求时允许详细解释。策略禁止重放聊天记录、暴露私有思考、内部执行链路和状态日志，以及声称执行纯文本运行时不具备的操作。

宿主仅转发当前助手消息的公开文本事件和规范最终文本，不会将 Agent/会话聚合历史、用户消息、思考内容、工具参数/结果或状态事件序列化为回复。之前的聊天仍作为独立历史消息保留在 UI 中。正常引用的标签、用户要求的代码、Unicode、空白和较长解释均会保留；不会用通用正则删除正文或任意缩短模型文本。

| 层级 | 检查内容 |
| --- | --- |
| 模拟 Adapter | 简洁确定性回复、明确语言要求、有界相关上下文、命令解析、Unicode、精确累计输出、停止、部分失败、回调背压 |
| Pi 输出与宿主 | 公开文本过滤、规范最终文本、过期/迟到事件、合成流驱动的真实 SDK 事件连接、私有资源、凭据隔离、取消、超时、崩溃核对 |
| API | 原子接受/outbox、幂等性、容量、所有者隔离、历史分页、SSE 重放/重同步、部分文本持久化、重启中断 |
| 演示数据 | 原子/重复导入、所有者冲突、用户修改保留、继续对话、多页历史和事件重建 |
| 浏览器 | 上下文隔离与简洁回复、断网/导航/刷新恢复、停止、发送重试、失败恢复、改名/归档、中文移动端 IME、Markdown/代码复制和本地化通知、回答与 UI 语言独立、分页、输入校验、语言菜单键盘操作、弹窗焦点范围及恢复 |
| 依赖门禁 | 锁文件变化、未审查或不兼容许可证、复制组件源码漂移 |

界面使用官方 shadcn Base UI 基础组件。语言测试操作可访问的组合框和列表框，而不是原生选择菜单。弹窗检查覆盖重命名 Dialog 和归档 AlertDialog，包括初始焦点、Tab 范围、Escape/取消、本地化标签和触发按钮焦点恢复。键盘测试在发送下一按键前等待目标选项实际获得焦点，避免异步焦点移动掩盖回归或选中上一个选项。

## 真实 Pi 验证

在 Git 忽略的根目录 `.env` 中私下配置已获授权的 `NEXRUN_OPENAI_API_KEY`，然后运行：

```sh
npm run test:pi
```

这项显式启用的检查会请求真实 OpenAI 服务，验证原生两轮上下文、对话隔离、持久会话权限、取消和配置失败。确定性测试能证明事件选择和应用行为，不能证明模型遵守每一条指令。真实回答质量与提供方身份验证仍需单独检查。此前真实尝试返回 HTTP 401；在提供可用凭据之前，不声称真实验证成功。
