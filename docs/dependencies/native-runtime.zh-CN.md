# 原生工作区运行环境审查

[英文版](native-runtime.md) · [机器可读清单](native-runtime.json)

本审查于 2026-11-05 针对现有单所有者本地 Mac 完成。清单记录了精确操作系统版本、已安装可执行文件的哈希、许可来源和运行结论。本实现不下载、修改或分发可执行文件、操作系统镜像或额外软件包。

已安装的 Apple `sandbox-exec` 使用默认拒绝的 Seatbelt 策略运行平台自有文件操作进程。只允许启动选定的 Node 可执行文件，拒绝读取用户文件内容、文件系统写入、网络连接和创建子进程。进程通过 stdin 接收有界文本快照，在内存中执行列表、读取、字面文本搜索和写入，通过 stdout 返回结果。数据库操作代理在发布持久化变更前，独立验证所有权、操作 ID、预期修订版和当前 Run 租约。导入文本不会作为代码执行。

Pi 宿主仍是在文件操作进程之外运行的受信应用代码，以便连接配置的模型。它只接收选定的服务商凭据和受控设置；文件工具通过 IPC 向操作代理请求执行。不启用仓库工具、Shell、动态发现的扩展或可执行技能。隔离进程失败时不能回退到未隔离的文件执行。

策略允许读取操作系统库/共享文件和目录元数据，但不允许通过 `/System/Volumes/Data` 读取内容。就绪检查验证私有测试文件、其 Data 卷别名和符号链接均无法读取，同时验证网络、宿主写入和子进程均被拒绝。父进程设置五秒截止时间、有界 stdin/stdout，以及 64 MiB V8 堆限制；堆参数不代表操作系统 RSS 上限。文件快照最多包含 128 个条目，每个文件最多 65,536 字节，序列化快照总大小最多 512 KiB；单次工具结果有更严格的输出限制。每次操作使用新的隔离进程。持久化工作文件保存在 PostgreSQL 不可变修订版中，不挂载宿主目录。

Apple 已安装的手册将 `sandbox-exec` 标为弃用。因此，本地 Provider 验证 macOS 26.5.1/build 25F80，以及已审查的 Node 22.20.0 arm64 和 Apple 可执行文件哈希，通过实际执行探测能力，并在不受支持、受限制或二进制版本尚未审查的宿主上默认拒绝。`nativeRuntimeIdentity()` 提供二进制和策略哈希供执行记录使用。它是本地 macOS 实现，不保证 VM、Linux 或不可信多租户工作负载。后续执行 Provider 需要独立审查与验收证据。

Apple 操作系统组件适用 [macOS Tahoe 26 许可](https://www.apple.com/legal/sla/docs/macOSTahoe.pdf)。本次审查采用在 Apple 硬件上继续使用已获许可系统的授权路径，包括适用的商业企业使用授权。这不授权分发 Apple 二进制文件，或运行共享、出租、云操作系统服务；这些用途具有独立限制，需要另外审查。Apple 说明[应以取得产品时适用的许可为准](https://www.apple.com/legal/sla/)。

现有 Node 22.20.0 运行时未经修改直接执行。其精确发行版 [LICENSE](https://github.com/nodejs/node/blob/v22.20.0/LICENSE) 包含 Node 的 MIT 条款和捆绑组件声明，不能将整个二进制文件视为只有 MIT 许可。本实现不捆绑 Node 安装包。客户自托管镜像或运行时分发需要保留并独立审查所选发行版的完整声明，不能以 npm 依赖清单代替。
