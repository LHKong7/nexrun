# Agent 管理配置

[英文版](admin-settings.md) · [运行指南](../README.zh-CN.md) · [测试说明](testing.zh-CN.md)

于 2026-11-05 实现。管理页面用于配置单一所有者应用的默认 Mock/Pi 运行时及 OpenAI 模型连接。

## 配置运行时

打开侧栏中的**设置**，或直接访问[管理配置页面](http://127.0.0.1:5173/admin/settings)。

1. 选择**模拟 Agent** 或 **Pi Agent**。
2. 从已安装 Pi SDK 支持的目录中选择 OpenAI 模型。
3. 设置 Agent 回复语言：跟随提问、英语或简体中文。此项独立于界面语言，并保留原始提示、引用内容、代码和历史。
4. 如需更换凭据，输入新的 API Key，然后选择**保存更改**。
5. 保存后可选择**检查凭据**；检查使用已保存的配置。

保存后运行时立即生效，API 重启后仍会保留。已保存的 Key 仅显示是否配置及来源，不会重新填入密码输入框。配置状态与连接检查成功状态分别展示。

## 凭据操作

| 操作 | 保存后的结果 |
| --- | --- |
| 密钥输入框留空 | 保留当前凭据策略和密钥 |
| 输入新密钥 | 加密存储，并优先于环境变量凭据 |
| 移除密钥 | 移除存储的密钥，同时禁用环境变量回退 |
| 使用环境变量密钥 | 清除存储的密钥，并明确启用环境变量回退 |
| 重置更改 | 丢弃表单中尚未保存的修改 |

环境变量回退优先选择 `NEXRUN_OPENAI_API_KEY`，其次为 `OPENAI_API_KEY`。修改正在继承的环境变量密钥后，需要重启 API。应用不会将模型 Key 写入 `.env`。

首次明确保存前，修订号为零的设置在启动时跟随服务端 `AGENT_MODE`、`PI_MODEL` 和 `AGENT_RESPONSE_LANGUAGE` 默认值。保存后，持久化的运行时、模型和语言选择优先于这些默认值。凭据回退继续由上表中的独立操作控制。

## 安全应用更改

配置提交与消息接受共用服务端准入门禁。Run 处于排队、执行、取消或调度器尚未结束收尾时，更新会返回 `SETTINGS_BUSY`。请停止或等待 Run 完成，再重新加载设置。更新不会中断正在进行的生成，也不会将已接受消息交给另一套配置。

每次保存都提交修订号。旧版本请求返回 `SETTINGS_CONFLICT`，不会覆盖更新的设置；请重新加载后再保存。确认回滚后，原运行时及修订号保持生效。如果无法确认数据库提交结果，API 会返回 `SETTINGS_COMMIT_UNKNOWN` 并关闭准入，避免继续使用可能过期的凭据；重启 API，从数据库恢复已提交状态后再接受工作。

在 Mock 与 Pi 之间切换，或为 Pi 选择不同模型时，需要新建聊天。已有历史仍可查看。同一 Pi 模型的凭据替换可以继续已有聊天。升级前尚未记录模型绑定的旧 Pi 聊天也需要新建。回复语言变化作用于后续回答，不会重写历史消息。

## 密钥存储与备份

模型 Key 使用 AES-256-GCM、随机 nonce 和绑定所有者的认证数据，加密存入 PostgreSQL 的 `admin_settings` 表。公开及管理 JSON 响应均不包含明文 Key 或密文。新 Key 输入和管理员解锁令牌只保存在组件内存中，应用不会将它们写入 URL、local storage 或 session storage。离开设置页面会清除密钥输入和解锁状态。

默认加密主密钥是独立的 32 字节文件，位于 `PI_STATE_DIR/configuration/encryption.key`；目录权限为 `0700`，文件权限为 `0600`。使用提供的 `.env.example` 时，对应 `.data/pi/configuration/encryption.key`。备份数据库时，应同时保留匹配的私有状态；仅有数据库备份无法恢复加密后的模型 Key。

若需使用部署系统管理的稳定主密钥，请私下将 `NEXRUN_CONFIG_ENCRYPTION_KEY` 设置为 32 个随机字节的规范 base64 编码。例如，可在本机生成：

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
```

通过服务端密钥配置提供该值，不要提交源码或包含在截图中。已有存储凭据时，更换或丢失加密主密钥会导致认证解密失败；启动 API 前应恢复匹配的主密钥。实现不会静默替换无法读取的凭据。容器部署需要持久化私有状态卷。

## 管理访问

未设置 `NEXRUN_ADMIN_TOKEN` 时，管理接口仅接受使用允许的本地主机名、直接来自回环地址的连接；修改操作还必须具有明确且受允许的本地 Origin。出现转发或代理请求头时，本地回退访问会被禁用。

共享部署应私下设置足够长的随机 `NEXRUN_ADMIN_TOKEN`，并为应用配置经身份验证的 TLS 访问。启用后，即使从 localhost 访问，管理接口也必须携带令牌。页面提供密码式解锁表单，仅在管理 API 的 Authorization 请求头中发送令牌；离开设置页面前，令牌只保存在内存中。普通聊天仍使用现有的固定开发所有者；管理员令牌用于保护配置，不会引入用户账号或组织角色。

服务端同时执行既有 Host/Origin 策略。请为部署配置 `ALLOWED_HOSTS` 和 `ALLOWED_ORIGINS`。反向代理不应被当作直接连接的本地管理员；共享访问时必须配置管理员令牌。

## API 与连接检查

| 接口 | 用途 |
| --- | --- |
| `GET /api/admin/access` | 返回令牌要求和本地访问元数据 |
| `GET /api/admin/settings` | 返回脱敏设置、修订号、模型目录和活跃 Run 数量 |
| `PATCH /api/admin/settings` | 通过乐观修订检查保存已校验配置 |
| `POST /api/admin/connection-check` | 检查已保存修订号对应凭据的模型元数据访问 |
| `GET /api/config` | 返回当前公开运行时元数据，包括回复语言 |

连接检查使用服务端 Bearer 凭据请求固定的 OpenAI `GET /v1/models/{model}` 接口，超时为五秒。它不会发送对话内容、不跟随重定向，并返回稳定诊断码，而非提供方原始响应体。这验证的是模型元数据访问，与成功生成回复是不同的验收项。参考[官方模型查询文档](https://developers.openai.com/api/reference/resources/models/methods/retrieve)及[身份验证说明](https://developers.openai.com/api/reference/overview)。

## 验证

2026-11-05 的本地检查通过了全部 90 项 Node 测试，无跳过，并通过 19 项浏览器场景、类型检查、lint、构建及既有许可证门禁。配置测试覆盖加密、重启恢复、环境变量回退、版本修订、确认回滚、未知 COMMIT 后关闭准入与恢复、授权、活跃 Run 保护、运行时立即生效、模型绑定及独立回复语言。丢失提交确认的回归测试验证：数据库更改已提交时，旧缓存设置变为不可用，已排队消息准入被拒绝，API 关闭，并在重启时恢复。浏览器测试使用合成 Key 和不联网的运行时/检查器测试替身；解锁测试模拟 HTTP 401 契约，实际接口授权由 Node 集成测试覆盖。

这些测试替身不能证明真实提供方调用成功。可以使用**检查凭据**验证已保存的 Key，再通过新建 Pi 聊天验证生成。独立的 `npm run test:pi` 冒烟脚本仍使用环境变量凭据，详见运行指南。本功能没有引入新的第三方依赖。
